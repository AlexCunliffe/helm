# Contributing

This project provides no support commitment or roadmap promises. Pull requests are welcome. Reviews may take time, and a change may not be accepted.

1. Read `CLAUDE.md`.
2. Select one small change.
3. Record the plan in `PROGRESS.md`.
4. Build the change.
5. Test the change on a development deployment.
6. Check the diff for private data and secrets.
7. Commit the change with a clear message.

Use generic examples. Keep credentials in deployment environment variables or ignored local configuration. Do not include customer data in a report or fixture.
