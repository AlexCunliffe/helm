# 01 · Vision and principles

Helm captures tasks and commitments, surfaces the next action, and records completed work. It is designed for someone who struggles with manual upkeep and needs the system to come to them.

## The three doors

1. Capture friction: accept an intent in one line or propose a task from an enabled source.
2. Surfacing failure: show one next action and a short brief where the user already works.
3. Re-entry cost: preserve the source link and a one-line account of the current state.

Unplanned work belongs in the same daily record as planned work.

## Principles

- Keep capture simple.
- Lead with one next action.
- Keep context with each task.
- Treat deferral as an ordinary choice.
- Show completed work without guilt.
- Keep the interface calm.
- Store categories as data.

Helm is a single-user task system. Durable knowledge belongs in a separate, linked vault.
